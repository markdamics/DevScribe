# Features

## Editor
- Canvas-based text editor (custom-drawn, not a native textarea)
- Multi-tab editing
- Multi-language syntax highlighting (Rust, JSON, TOML, Java, Python, JavaScript, TypeScript, C++)
- Line numbers
- Block indent / dedent
- Toggle line comment
- Find in file
- Find and replace
- Go to line
- Breadcrumb bar
- JSON tree view
- Markdown preview
- Diff view (working tree)
- Word wrap / density settings
- Adjustable text scale

## Language Intelligence (LSP)
- rust-analyzer, jdtls, pyright, typescript-language-server, clangd support
- Inline diagnostics (errors/warnings)
- Problem lens (inline diagnostic messages)
- Hover popups
- Go to Definition
- Find All References
- References/Locations panel
- Dot-completion popup
- Code outline
- Language server auto-install

## AI Assist
- AI chat panel
- Claude agent integration
- GitHub Copilot agent integration
- Copilot-style inline code completion
- Chat sessions (new session, session history)
- File attachments in chat
- Actions menu
- Fix bug / explain selection from chat
- Diff preview of AI-proposed changes
- Permission modes for agent actions

## Project & File Management
- Sidebar file tree
- Open folder / New project / Close project
- Recent projects
- New file / New folder
- Reveal in tree
- Reopen closed tab
- Close tab / Close other tabs
- Copy path
- File system watcher (live external changes)
- Hidden files toggle

## Git Integration
- Git status (changes, ahead/behind)
- Working tree diff view

## Search
- Project-wide search
- Fuzzy file/command matching

## UI / UX
- Command palette
- Settings panel (Explorer, Editor, Toolchains, Shortcuts, About)
- Keyboard shortcuts reference
- Context menus
- Tab bar with overflow menu
- Status bar
- Toast notifications
- Flash/highlight feedback
- Light/dark theme
- Welcome screen
- Custom title bar
- Session persistence (restore last state on launch)
